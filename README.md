# Getsure Controlled Bot for Material Handling 

## 📝 Description
It's a mechatronics based iot system where an operator inputs direction using gestures and the bot  takes the load Along that direction. Mainly we used gyro sensor for gesture input, L298 dual motor driver board for actuation and esp32 for processing. Usually material handling is done manually in MSMEs.  We build this for msme industries because in MNCs and all, material handling is already under complete automation. But small warehouses and industries still use manual labour. This bot doesn't completely replace humans from a workplace. To operate we still need people so it's a human centric application that can reduce job displacements and can also create jobs like a technical team for the bot's calibration and repair. And it's also much economical than existing automation tech.

## 🚀 Project Details
- **Theme:** INDUSTRY 5.0 + IIoT
- **Tech Stack:** ESP 32, Arduino IDE
